---
title: "Corrosion user guide"
---

Corrosion turns MIDI notes into struck, bowed, scraped and blown metal. This guide takes you from installing it to building your own sounds, and it documents every control.

## Where to start

- **New to Corrosion?** Read [What is Corrosion](/wiki/getting-started/what-is-corrosion/), then [install it](/wiki/getting-started/installation/), [play your first note](/wiki/getting-started/first-note/) and take the [10-minute tour](/wiki/getting-started/tour/).
- **Don't want to install anything yet?** [Play it in the browser](/wiki/getting-started/web-app/): the web app runs the same engine and editor.
- **Looking up one control?** The [parameter reference](/wiki/reference/) has a card for each one, with its range, its default and audio examples. In the plugin, hover the ⓘ badge next to a control's label for a short explanation.
- **Something sounds wrong?** Start with [Troubleshooting](/wiki/troubleshooting/).
