Presets are small text files you can copy, mail, back up and share. A preset saved in the plugin opens in the web app, and the other way round.

**Try it:** click **Open folder** in the **PRESET BANK** box and open one of your presets in a text editor. It's readable: the name, the object, the exciter and a list of values.

## File format

Each preset is one `.corrosion-preset` file in JSON, a plain text format. It stores the preset's name, a schema version (currently `"4"`), and the value of every control by its parameter name; Kit presets add their pads.

You can edit one by hand if you're careful, but there's rarely a reason to: anything you can set in the editor, you can save from it. A value out of range is clamped to the nearest valid one when the preset loads.

## Between the web app and the plugin

Both sides use the same files, so moving a preset across is two clicks.

**From the web app to the plugin:** in the web app, click **Download preset** and give it a name; the browser saves a `.corrosion-preset` file, usually in your Downloads folder. In the plugin, click **Import…** in the **PRESET BANK** box and pick it. It lands in the folder chosen next to **Save**, and loads.

**From the plugin to the web app:** in the plugin, click **Export…** and save the file somewhere you'll find it. In the web app, click **Open preset…** and pick it. It loads, and the web app keeps it with your browser presets.

**Without the dialogs.** If Import and Export say your system has no file dialog, copy files by hand: **Open folder** shows your preset folder (it creates it if this is your first preset), and anything you copy into it, or into one of its subfolders, appears under **User** the next time you open the preset menu. The folder is here:

- **Windows:** `%APPDATA%\Corrosion\Presets`
- **macOS:** `~/Library/Application Support/Corrosion/Presets`
- **Linux:** `~/.local/share/corrosion/presets` (or `$XDG_DATA_HOME/corrosion/presets` if you've set it)

If a copied preset doesn't show up, see [Troubleshooting](/wiki/troubleshooting/#missing-presets).

## Older presets

Corrosion keeps loading presets made by older versions, and makes them sound as they did, even where a control has changed meaning since:

- **Diode stage:** presets from before **Asymmetry** existed load with **Softness** and **Asymmetry** at 0, the hard, symmetric clip they had.
- **Onset Level:** presets from before it existed get the level their **Onset** used to set.
- **Wander Rate:** presets from before it existed get the rate their **Pos Env** used to set, and Pos Env 0.
- **Kit mode:** presets that used the old Kit mode, which mapped keys to objects, load in **Tonal**.

Nothing is rewritten on disk: the conversion happens each time the preset loads. Save it again to store it in the current form.
