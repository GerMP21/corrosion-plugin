**SCALE**, in the header, sets the size of the editor window, from 50 % to 150 % in 5 % steps. The default, 75 %, opens an 810 × 630 window that fits most laptop screens.

**Try it:** open **SCALE** and pick 100 %. The whole editor grows, text and knobs alike.

## Changing the scale

Pick a size from the menu and the window resizes to match. Everything scales together, so the layout never changes, only its size.

- **On a high-resolution screen**, if the text looks small, try 100 % or more.
- **On a small screen**, go down until the window fits. When the window is shorter than the editor, the panels scroll and the piano strip stays pinned at the bottom.

The scale is saved with your host project, so each project opens at the size you left it. It's the one setting presets don't store: loading a preset never resizes your window.
